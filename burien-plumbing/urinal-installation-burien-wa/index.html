    Urinal Brands We Install in Burien, WA

    Brand choice is mostly about parts support. We recommend brands whose valves and cartridges are easy to get locally, so repairs never wait. We install all of them. Spec sheets come first.

    Old Urinal Removal and Replacement in Burien

    Old urinals come off harder than they went on. Rusted bolts and seized valves often have to be cut, so we protect the tile while working. We never reuse the old gasket. The flange gets cleaned to bare metal.

    Urinal Installation Cost Factors in Burien, WA

    Carrier work is the biggest cost swing. Reusing a carrier and lines is cheap, while new carriers and pipe runs through finished walls cost more. Sensor valves add a few hundred. We itemize each piece.

    Residential Urinal Plumbing in Burien, WA

    Home urinals use the same rules as commercial ones. The drain is usually 2 inch, the trap is built into the china, the fixture needs a vent within code distance, and the flush valve needs either a 3/4 inch supply or a lower-flow residential valve on 1/2 inch. Your city may want a permit. We check that first.

    Waterless Urinal Upgrades in Burien

    Switching to waterless is mostly a fixture swap. We remove the flush valve, cap the supply and set the waterless bowl on the same carrier. Some codes want the supply left in place. That allows a future change back.

    Waterless Cartridge Urinals in Burien

    Each waterless brand uses its own cartridge. Falcon, Waterless Co, Kohler and Zurn units all trap odor differently, and the cartridge or sealing liquid has to be replaced after a set number of uses, which in a busy restroom can mean every few months. A replacement schedule comes with the install. Spare cartridges should stay on site.

    ADA Urinal Installation in Burien

    Accessible urinals start at the carrier. The carrier gets set for a 17 inch rim, the floor space stays clear, and the flush control stays reachable. We measure the rim twice. Inspectors measure too.
