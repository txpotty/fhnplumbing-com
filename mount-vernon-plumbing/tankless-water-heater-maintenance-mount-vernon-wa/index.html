    Error Code Diagnostics in Mount Vernon, WA

    Codes like Rinnai LC, Navien E003 or Noritz 90 tell us a lot about what is going wrong. We read the code history, test flame rods, flow sensors and igniters and check gas pressure at the inlet.     Condensing Unit and Neutralizer Service in Mount Vernon
